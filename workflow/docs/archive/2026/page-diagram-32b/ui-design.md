# UI Design: page-diagram-32b

> **UI 表面**：gui  
> 依据 Spec：`workflow/docs/features/page-diagram-32b/spec.md` · 依据 Design：`design.md` · 依据标准：`workflow/docs/standards/ui.md`  
> **主题**：沿用既有 light/dark 合同（本 Spec **未**要求改主题）；结构图/hex 复用现有 CSS 变量并扩展区域/选中 token。单主题新皮肤 **不**引入。

## 目标与任务

- **主目标**：在真实 8KB heap 页上，按 32B 网格扫读字段边界，点击高亮，折叠 free space，并与 hex 双向对齐同一字节区间。
- **第二轮增量目标**：宽格直接读到字段具体值（P0-10）；详情与格内值一致（P0-11）；选中后 hex 自动定位到高亮首字节行，免 256 行长滚（P0-12、Q7）。
- **关键任务（优先级）**：浏览 32B 结构图 → 点选字段看边界/名称与值 → 对照自动定位后的 hex 高亮 → 折叠/展开 free →（次要）详情区 flag/列值等基线能力。
- **信息优先级**：结构图网格（边界 > 值 > 名称）> 选中高亮与详情 > hex > 壳层/Context strip（本项不重做 strip）。

参考图仅为示意图（非像素稿）：分区语义与字段名可借鉴；装饰/配色可优化（P0-9）。

## 信息架构与元信息

### 主区分区（本项改动面）

```text
┌─ Main（保留壳层 chrome / strip / navigator）──────────────┐
│  Structure diagram（32B 逻辑行）                           │
│    [PageHeader 字段格]                                     │
│    [ItemId 槽位 … 按 32B 换行]                             │
│    [FreeSpaceBand：折叠/展开]                              │
│    [HeapTuple 字段格 …]                                    │
│  Selection detail（既有 flag/列值/HOT；保留）              │
│  Hex dump（32B/行；可折叠高度控件可保留）                   │
└────────────────────────────────────────────────────────────┘
```

- **元信息**：Context strip 字段集与基线一致；本项不新增必显元信息。
- **壳层**：连接表单、表列表、主题入口 **不改**（除非结构图/hex 局部间距）。

### 结构图信息优先级

1. 字段边界（始终可见，即使标签缩写或仅显示值）
2. 字段具体值（值模式下优先于字段名）+ 选中态
3. 字段名/缩写（放不下时降级到 tooltip / 详情）
4. Free 真实跨度文案与折叠控件
5. 区域标注（PageHeader / ItemId / free / Tuple）——次要，不遮挡网格

## 流程

1. 用户已按基线加载页 → 主视图为 32B 结构图（非旧区块列表）。
2. 扫读：自上而下低→高偏移；同行内左→右为低→高列；宽格直接显示具体值（如 `t_xmin` 事务号），窄格显示缩写标签。
3. 点击字段格（或键盘激活）→ 该字段选中高亮；hex 同步高亮完整 `ByteRange`；Selection detail 打开/更新并显示同一主值。
4. 若 hex 处于折叠 → 自动展开（Q7）；hex 自动滚动一次，使高亮首字节行进入可视区（近顶约 1/3）。同一字段重复点击不再滚动。
5. Hex 点某字节 → 若落在已映射字段 → 结构图该字段（含跨行片段）同步高亮；hex **不**因自己发起的选中而滚动。
6. Free：默认展开（空洞压缩条）或沿用产品默认；用户折叠 → 紧凑断裂带仍显示 `free space` + `[start,end)` + 字节数；再展开恢复；hex 内容/行数不变。
7. 窄字段：格内缩写；hover/聚焦/选中 → tooltip 和/或详情区全文（含全名与主值）。
8. 基线：详情区 flag 逐位、列值、跨块 ctid、Refresh diff 仍可用。

## 状态

| 状态 | 呈现 | 用户可执行动作 |
|---|---|---|
| 初始 / 未加载页 | 沿用基线（无结构图） | 选表 Load |
| 加载页 | 主区局部指示；壳层稳定 | 等待 |
| 空（无 NORMAL tuple） | 结构图仍含 header/ItemId/free；提示无 tuple（基线文案可保留） | 浏览/折叠 free |
| 成功 `page_loaded` | 32B 结构图 + hex(32) + 详情 | 点选、折叠、hex 点选 |
| 选中字段 | 字段片段 + hex 区间高亮可区分；详情区更新并显示同一主值 | 改选；看 tooltip |
| 格内值模式（宽度足够） | 格内显示完整主值；同格可再显示缩写标签行 | 点选；hover 看全名 |
| 格内标签回退（宽度不足或无主值） | 仅缩写标签；边界不变、不合并、不显示截断值 | hover/聚焦/选中看全值 |
| hex 自动定位 | hex 滚动一次，高亮首字节行落在可视区（近顶约 1/3）；短暂行强调 | 手动继续滚动（不再被抢） |
| hex 已可见 / 同区间重复点击 | 不滚动、无跳动；仅选中态与详情更新 | 继续浏览 |
| hex 折叠 + 非 hex 发起的选中 | hex 自动展开（按钮与 `aria-expanded` 同步），随后定位 | 再次手动折叠 |
| Free 折叠 / 展开 | 断裂带高度变化；跨度文案仍在；hex 行数不变 | 切换折叠 |
| `diff_active` | diff 样式与选中/hex 高亮可区分 | 再刷新 |
| 错误（非 8KB 等） | 沿用基线：明确错误；**禁止**画错误 32B 图 | 换页/环境 |
| 部分失败（未知列/TOAST） | 该列降级展示；网格其余可用 | 继续浏览 |

## 表面专属设计

### gui

#### 布局与层级（Q1）

- **垂直**：Header/ItemId 在上，free 中，tuple 在下；与 hex 同向。**禁止**整页倒置。
- **水平**：每逻辑行 32 列；字段按 `[start,end)` 切片段占格。
- 结构图占主区最大面积；hex 在下（默认约 30% 高，可沿用折叠）。
- 区域标签可用小标题或左边注；**禁止**大卡片墙盖住网格。

#### Free space（Q5 / P0-7）

| 态 | 视觉 |
|---|---|
| 展开 | 空洞压缩条（非真实比例撑满）；标注 free + 真实跨度/字节数；整段可点选 |
| 折叠 | **紧凑断裂带**（单行量级高度）；文案含 `free space` 与 `[start,end)`/字节数；**不**生成铺满的空 32B 行 |

- 折叠控件：可见按钮或等价控制；`aria-expanded`；Tab + Enter/Space 可操作。
- 折叠**只**变结构图高度，不变 hex。

#### 字段标签（Q2 / P1-1）

- 宽格：尽量全名；窄格：缩写/截断（如 `xmin`、`off`）。
- 全文：`title`/tooltip，且选中时详情区显示 `fullLabel`。
- **禁止**为塞文案而合并相邻字段边界。

#### 格内值与标签（P0-10 / P0-11）

优先级：**边界 > 完整主值 > 字段名**。

| 格内可容纳 | 呈现 | 名称从哪来 |
|---|---|---|
| 主值 + 缩写标签（各自独占一行，均不截断） | 两行堆叠：上行小字号缩写标签，下行主值（`mono`，稍强对比） | 格内 + tooltip |
| 只容纳主值 | 单行主值 | tooltip（`title` = 全名 + 主值）+ 详情区 |
| 主值放不下，或该字段无单行主值（free / nullbits / data） | 回退 Q2 标签模式（缩写标签） | tooltip + 详情区 |

- **禁止**：截断主值、以省略号显示主值、为容纳值而合并或挪动字段边界、值文本溢出侵入邻格。
- 跨行字段：主值只在**最宽片段**渲染一次，其余片段保持标签模式；所有片段选中态与高亮仍同步（Q3 / P1-2）。
- ItemId 4B 槽位：`off | flag | len` 视觉三分内各自按同一规则显示值或标签（选中仍为整 4B，见「ItemId 视觉子段」）；LP 状态色/角标不被值文本挤掉。
- 值文本使用等宽字体与 `font-variant-numeric: tabular-nums`，与 hex 数字观感一致；标签行字号小于值行。
- 详情区：选中后显示 `fullLabel` + **同一主值串**（同源，`design.md` 决策 6）；既有 flag 逐位、列值、ctid 等子块保留在主值下方。
- 视口变化/缩放导致宽度不足时**必须**自动回退标签模式；回退是布局态变化，不得触发选中或滚动变化。

#### 跨行字段（Q3 / P1-2）

- 每个 32B 行画该字段落在此行的片段；片段共享选中态。
- 点任一片段 = 选中整字段；hex 高亮连续 `[start,end)`。

#### ItemId 视觉子段

- 每 4B slot 内画 `off | flag | len`（或等价）三分视觉；LP 状态（UNUSED/NORMAL/REDIRECT/DEAD）可用色或角标区分。
- 选中任一子标签 → 高亮该 ItemId 完整 4B（见 `design.md`）；hex 同步该 4B。

#### Hex（Q6 / P0-6）

- 32 字节/行；行首偏移十六进制 ≥4 位（`0000`、`0020`…）。
- 行数 = `ceil(pageSize/32)`（8192→256）。
- ASCII 旁路：**可选**；若做须与字节列对齐且不破坏点选。
- 高亮类名与结构图选中共用同一 `highlight`。

#### Hex 自动定位与折叠自动展开（P0-12 / Q7）

- 触发：**非** hex 面板发起的选中变化且区间与上次不同 → hex 滚动容器滚动**一次**。hex 自身点选、重复点击同一字段、用户手动滚动后无新选中：**不滚动**。
- 落点：高亮首字节行进入可视区，**宜**位于可视区顶部约 1/3（避免贴顶被 hex 上边框/滚动阴影切割）；容器高度允许时整段 `[start,end)` 尽量可见；页尾区间以内容末端为界，不留空滚动。
- 视觉反馈（使跳转可感知）：首字节所在行短暂强调（约 600–800ms 行底色/左侧标记淡出），仅作定位提示；高亮字节仍由常驻 `--hex-hl` 标记，二者**须可区分**且不改变字节色值语义。`prefers-reduced-motion: reduce` 时滚动用 `auto`、行强调改静态短暂显示或省略，**不得**因此丢失字节高亮。
- 折叠自动展开的可发现性：
  - 自动展开后折叠按钮文案同步为 `Collapse hex`、`aria-expanded` 为 `true`；用户可立即手动再折叠，且仅当「已折叠 + 新的非 hex 选中」时才再次自动展开；
  - 附一条 `aria-live="polite"` 简短播报（如 `hex expanded, scrolled to 0x1f20`），供屏幕阅读器与视觉扫读共同感知；文案不常驻占位。
- 布局稳定：滚动**只**发生在 hex 滚动容器内；hex 面板整体完全不在主区视口内时，**允许**附带一次最小幅度的主区滚动使面板可见，部分可见时**禁止**滚动主区。
- 焦点：自动滚动**禁止**移动键盘焦点（焦点保持在被激活的结构图字段格上），键盘可达性不回退；键盘激活（Enter/Space）与鼠标点击触发同样的定位。

#### 密度与响应式

- 等宽字体用于偏移/hex/窄标签/格内值；结构图正文字号约 11–13px，行高偏紧；值模式两行堆叠时行高统一，避免同一逻辑行高低不齐。
- ≥1280px：结构图与 hex 上下分栏；宽视口下更多字段进入值模式。
- 窄屏：结构图横向滚动优于压扁列导致边界不可辨；横向滚动使列宽保持时值模式**可**保留。
- 值模式/标签模式切换只改格内文本与行数，**禁止**改变字段边界位置与网格列宽语义。

#### 焦点与键盘

| 目标 | 行为 |
|---|---|
| 字段格 | `tabIndex=0` 或罗盘式焦点；Enter/Space 选中；激活后 hex 自动定位，焦点不移动 |
| Free 折叠控件 | 可聚焦；Enter/Space 切换 |
| Hex 折叠控件 | 可聚焦；`aria-expanded` 与自动展开同步 |
| Hex 字节 | 保留可点/可键盘（与基线一致；32B 行）；hex 内激活**不**触发自动滚动 |
| 跨块 ctid 等 | 基线保留 |

- `:focus-visible` 高对比轮廓（两主题可见）；值模式不得削弱焦点轮廓可见性。
- 自动定位有 `aria-live="polite"` 播报；**禁止**用焦点跳转替代播报。
- Flag/infomask：保留 hover/聚焦逐位解读（详情区）；**不**做参考图类常驻图注（Q4）。

#### 视觉语义

- 复用既有 token：`--region-header` / `itemid` / `free` / `tuple`、`--hex-hl`、`--diff`、`--focus`。
- 新增/明确：`--field-selected`（结构图选中，可与 hex-hl 呼应但与 `--diff` 可分）；`--hex-locate`（自动定位后的行强调，须与 `--hex-hl`、`--diff`、`--field-selected` 三者可区分）。
- 格内层级：值文本对比度 ≥ 标签文本；标签为次要色/小字号，避免值被标签淹没。
- 参考图配色（蓝 ItemId、绿 xmin 组、橙 ctid）**允许**作语义提示，非强制像素。
- 主题策略：沿用基线 `data-theme` light/dark 与默认偏好；不新增模式；新控件两主题可读。
