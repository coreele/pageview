# 文档规范

Docs as Code：文档与相关代码同仓库、同分支、同审阅演进。

- **A. 文档工程** — 分类主责、Plan 文档影响、用户与运维文档要素、链接校验。
- **B. 产物整理** — 工作流产物交接前的原位自检。

---

## A. 文档工程

### A.1 分类与主责

| 类型 | 主责 | 典型位置 |
|---|---|---|
| 开发 / API / 配置 | Developer | 代码注释、README、接口与配置说明 |
| 架构决策 | Planner | `workflow/workspace/<id>/design.md` |
| 界面与交互 | Planner | `workflow/workspace/<id>/ui-design.md` |
| 需求规格 | Analyst | `workflow/workspace/<id>/spec.md` |
| 部署与排障 | DevOps | [ops/](../../ops/) |
| 工作项与流程 | Manager | `workflow/workspace/<id>/main.md`、[STATUS.md](../../STATUS.md) |

只改本职文档；跨角色的文档变更须在 Plan「文档影响」中声明。工作流产物的结构见 [templates/](../templates/)。

### A.2 Plan 文档影响

每份 Plan 须分别说明三类文档的更新路径，无需更新则标 `N/A` 并写理由：**开发文档**（注释、API、配置、开发者 README）、**用户文档**（功能说明、操作指南）、**运维文档**（部署、监控、排障、备份恢复）。

### A.3 用户 / 运维文档最低要素

适用于用户可见与运维可执行文档：适用对象（必须）、前置条件（必须）、操作步骤（必须）、预期结果（必须）、失败处理（适用时）。

工作流产物与纯架构笔记**不**套本表，按各自模板 + §B 整理。

### A.4 链接与示例校验

Reviewer 或 QA 须核验链接、路径、命令与配置示例可用：实跑、对照仓库结构或确认可访问。错误引用须在合并前修正。

工作流自身的文档按 `workflow/WORKFLOW.md` §1「路径写法」选用链接或反引号路径，两种形式都由 [wf-check.py](../tools/wf-check.py) 校验。

## B. 产物整理

**对象：** `spec.md`、`design.md`、`ui-design.md`、`plan.md`、`dev-notes.md`、`review.md`、`qa-report.md`、`main.md`。

**时机：** 初稿或阶段更新完成后、交接前，每次只处理一份。

目标是**更好扫读，不是更短**。

### B.1 原则

| 原则 | 含义 |
|---|---|
| 可读优先 | 顺着标题与模板能扫读；不为缩短牺牲衔接句与必要背景 |
| 轻度整理 | 只删无信息量的复述与套话；禁止电报体、关键词堆砌、表内表下双份 |
| 结构服从模板 | 枚举、链接、短标签进表；长理由与背景进段落或「进度笔记」 |
| 语义保全 | 不改合同、结论、门禁强度与可验证性；存疑就保留 |

### B.2 步骤

1. 读初稿、模板与直接依据。
2. **必须保留**：规范强度词（必须 / 禁止 / 允许）及其条件例外；ID、路径、命令、状态、枚举；合同、验收、证据、结论、风险、阻塞与恢复条件；模板必填项；不重复的简短背景。
3. **允许**：合并相邻同义复述；验收与 Review 保持「要求 → 证据 → 结果」；阻塞保持「未验证项 → 原因 → 风险 → 恢复条件 → 复测范围」；删纯套话。
4. **禁止**：单元格内塞长句理由；表下用电报体重抄整表；多字段挤一行；为缩短折断路径；删掉仍有区分度的背景「只为变短」。
5. 对照初稿核对保留项与模板结构；不确定就保留原文。

不臆造字段；模板缺项报告作者补充，不猜值。

### B.3 示例

**同义复述 → 合并。** 整理前：

> P0-2 要求超过 10 MiB 的文件返回 `FILE_TOO_LARGE`，且不得创建记录。10 MiB + 1 byte 文件返回该错误码，新增记录为 0，因此 P0-2 已通过。这里再次说明，错误码正确并且没有产生记录。

整理后：

> P0-2：超过 10 MiB 的文件必须返回 `FILE_TOO_LARGE`，且不得创建记录。实测 10 MiB + 1 byte 返回该错误码，且未新增记录。结果：通过。

**枚举进表，理由进笔记。** 差：单元格写 `skipped（既有系统介绍，无新增行为合同……）`。好：单元格 `skipped`，进度笔记写「Spec 门禁跳过：既有系统介绍与架构文档化，无新增行为合同。」
